# Soft Matter / 软体实验室

根据用户提供的 32 秒视频制作的本地浏览器交互版本。现有原版果冻块、小熊、卡通猫头、卡通狗头和卡通恐龙五种形状。

## 运行

安装有 Node.js 的电脑上，双击 `启动游戏.cmd`，或在此目录执行 `node server.cjs`，打开 http://127.0.0.1:4173 。如果首次打开时服务器尚未就绪，刷新页面即可。关闭服务终端即停止服务。所有渲染依赖已放在 vendor 内，运行不需要联网。

## 操作

- 在果冻表面按住鼠标或触摸拖动，可拎起、拉伸；抓住边缘可掀起和翻转。松手后受重力下落。
- 双击果冻或点击“弹一下”，从空中释放，落地压缩、碰撞回弹并停稳。
- 切换预设颜色或选自定义颜色。
- 调节弹性、阻尼、通透度和 HDRI 旋转角度；暂停、继续或重置当前形状。

## 实现与边界

Three.js WebGL 物理材质、真实摄影棚 HDRI 反射与环境折射。运动采用 120 Hz 固定步长，包含重力、抓取点弹簧、扭矩、四元数旋转、转动惯量、接触点法向冲量、摩擦和恢复系数；外层网格负责软体拉伸与碰撞压缩。摄像机固定约 18° 轻微俯视。使用可变形三维网格而非图片，保证鼠标实时塑形。

这是参考视频的近似实现，并非原作源码。物理是刚体运动与软体表面的混合模型，不是完整有限元/体积软体求解，尚无自碰撞。地面透光斑采用随高度、颜色和透明度变化的实时近似，不是光线追踪焦散。

运行 `node physics.test.mjs` 和 `node shapes.test.mjs` 验证自由落体、地面约束、回弹能量衰减、停稳、默认弹性拎起、不同抓取点的相反扭矩，以及五种网格的法线朝向和掉落稳定性。

界面保留浅灰舞台、左上衬线标题、中央彩色软体、右下参数面板和简约页脚；增加中文操作提示与明确的重置/暂停控件。手机录屏外框和字幕不属于复刻范围。

## 验证记录

通过 Codex 内置浏览器检查桌面窗口及 390 × 844 手机视口。验证拖拽、颜色切换、弹性数值更新、弹跳、暂停显示“继续”和重置恢复默认参数。检查标题、布局、配色、材质高光、参数间距及手机布局。修复了过曝、初始形状过于规整和环境贴图预过滤警告。与参考仍有折射、复杂形变和原参数文字无法从视频清晰辨认的差异，不声称像素级一致。

## HDRI 与第二轮对照

- 最终环境贴图：`assets/pav_studio_03_2k.hdr`，Poly Haven 的 [PAV Studio 03](https://polyhaven.com/a/pav_studio_03)，作者 Grzegorz Wronkowski，CC0。包含窗户、矩形柔光箱和摄影棚结构。资源已本地保存。
- 原片未提供 HDRI 文件或名称，因此使用同类型摄影棚素材；不能确认是原片所用的同一张图。
- 使用 HDRLoader 读取高动态范围数据，PMREM 用于表面反射，折射方向采样用于玻璃内部环境，结合屏幕空间透射。环境仍为近似，不是光线追踪的多次折射。
- 内置浏览器复查了轮廓、起伏、反射细节、体色、阴影和 390 × 844 手机布局；对照原视频关键帧检查。拖拽、换色可用，检查时无控制台错误或警告。此次没有修改界面文案。
- 剩余差异：原片的具体 HDRI、光照方向、瞬时形变和多次折射无法从录屏完整还原，不宣称逐帧一致。

当前默认：西瓜果冻，环境角度 42°。果肉采用红到黄渐变，厚瓜皮为宽幅不规则深浅绿条纹；正反面采用均匀分布的 Delaunay 三角网格，去除中心极点。原有物理参数保持不变。

小精灵由球体变形生成，保留饱满的前后厚度和环绕底部的波浪裙边；小熊加厚头部、腹部与脚掌，移除眼睛和鼻子等五官小点。两个主体均为 3,380 个三角面，沿用现有拖拽和碰撞物理。
